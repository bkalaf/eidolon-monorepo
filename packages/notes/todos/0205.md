Populate .env (copy from .env.example), run yarn install, then yarn workspace @eidolon/api-service dev alongside yarn workspace @eidolon/edge dev to validate the proxy + auth flow locally.
When ready for production, run yarn workspace @eidolon/api-service build, deploy the Nitro server on DO, point apps/edge’s API_ORIGIN/EDGE_ALLOWED_ORIGIN at it, and run yarn workspace @eidolon/edge deploy.
